# AU_811533_Final_Exam

# Mapping Chinese Churches in Japanese-Occupied Hong Kong (1941–1945)

## Overview
This project explores the spatial distribution and social functionality (e.g., safety net services) of Chinese Christian churches during the Japanese occupation of Hong Kong using R and GIS spatial analysis.

## Dataset Description
`wartime_churches_clean.csv`: Cleaned spatial dataset of Christian churches in Japanese-occupied Hong Kong (1941–1945), compiled from historical archives, directories, and digital mapping resources with columns for church name, location/address, district, coordinates, denomination, operational status, and safety net/welfare function.
